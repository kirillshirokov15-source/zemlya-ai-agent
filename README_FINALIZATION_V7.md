# Zemlya AI – Finalization V7

Объединённые шаги 3 + 4 + 5.

## Что входит

### 1. Контакты
– поиск ЛПР и публичных деловых контактов;
– максимум 10 сильнейших проектов за запуск;
– Project Score от 55;
– persistent cache по ИНН на 30 дней;
– если контакт компании уже находился раньше, повторный Tavily/OpenAI поиск не запускается;
– один ИНН внутри одного запуска также обрабатывается один раз.

### 2. Финальная проверка
Без дополнительных web/API запросов:
– приостановленные проекты;
– уже начавшееся строительство / разрешение;
– участок уже определён;
– модернизация существующей площадки;
– неподтверждённая компания;
– наличие прямого контакта ЛПР.

После проверки система ещё раз корректирует Project Score / Sales Score
и сортирует итоговый список.

### 3. Финальный интерфейс
Один список без CRM:
– идти сверху вниз;
– 90–100 – можно контактировать сейчас;
– 70–89 – сильный лид, дособрать прямой контакт;
– 50–69 – сначала проверить;
– <50 – низкий приоритет.

## Почему быстрее

Раньше контакты искались повторно на каждом запуске.
Теперь успешный результат сохраняется в `company_contact_cache` на 30 дней.

Поэтому:
– первый запуск для новой компании остаётся дорогим;
– следующие запуски для той же компании намного быстрее;
– повторные проекты одного ИНН внутри одного запуска не вызывают второй поиск.
