# Zemlya AI – Contacts V6

Шаг 3 из 5 – ЛПР и публичные деловые контакты.

## Что добавлено

После Company Resolution система ищет:
– собственника / генерального директора;
– директора по развитию / инвестициям;
– директора по строительству / недвижимости / земельным вопросам;
– руководителя проекта;
– при отсутствии прямого ЛПР – общий корпоративный телефон/email.

Контакты извлекаются только из реально найденных публичных источников.
Email не генерируется по шаблону. Телефон/email проходят базовую структурную проверку.
Источник контакта сохраняется.

## Важное изменение Sales Score

Статус «Готов к контакту» теперь возможен только если реально найден ЛПР
с телефоном или email. Высокий score без прямого контакта останется
«Высокий потенциал» и получит действие «Найти ЛПР и контакты».

## Railway

Новых Variables пока не требуется.
Используются существующие TAVILY_API_KEY и OPENAI_API_KEY.

После push:
1. Redeploy zemlya-ai-agent
2. Redeploy zemlya-worker
3. Запустить один новый поиск

После результата проверяем верхние 10–15 строк:
– появились ли реальные имена ЛПР;
– есть ли телефон/email;
– соответствует ли контакт компании;
– «Готов к контакту» стоит только там, где есть прямой контакт.
