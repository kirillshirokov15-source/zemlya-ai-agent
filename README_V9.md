# Zemlya AI V9 – накопительная база и финальный dashboard

Новый поиск больше не заменяет рабочую базу целиком.

Для активных лидов:
– найден снова – статус «Актуален», счётчик пропусков сбрасывается;
– пропущен 1 поиск – остаётся в базе;
– пропущен 2 поиска подряд – «Проверить актуальность»;
– пропущен 3 поиска подряд – архивируется из рабочего списка.

Слабые записи verification_pool архивируются после одного пропущенного поиска, чтобы не засорять список.

Установка:
1. заменить `app/services/project_persistence.py`
2. заменить `app/api/routes/projects.py`
3. redeploy `zemlya-ai-agent`
4. redeploy `zemlya-worker`

Новых переменных окружения нет.

После деплоя просто откройте `/projects/dashboard`. Новый поиск сразу запускать не обязательно.

Рекомендация – один новый поиск в неделю, при интенсивной работе максимум два раза в неделю.
