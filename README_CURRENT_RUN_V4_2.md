# Zemlya AI – Current Run Fix V4.2

Причина старых дублей и старых Sales Score:
`lead_projects` хранит историю всех запусков, но старые строки оставались `is_active = TRUE`.
Dashboard `/projects` не фильтровал их, поэтому старые лиды с Sales Score 100
оставались сверху даже после нового Quality Gate.

## Что исправлено

– после успешного сохранения нового запуска все строки, не встреченные в этом запуске,
  получают `is_active = FALSE`;
– данные не удаляются – история остаётся в PostgreSQL;
– `/projects` и Excel теперь используют только `is_active = TRUE`;
– сортировка – Sales Score → Project Score → Lead Score;
– dashboard превращён в один текущий список без CRM-логики «в работе»;
– новые диапазоны Sales Score:
  90–100 готов к контакту,
  70–89 высокий потенциал,
  50–69 требует проверки,
  0–49 низкий приоритет.

## Заменить два файла

app/services/project_persistence.py
app/api/routes/projects.py

Старые записи останутся в БД как история, но исчезнут из основного списка.
